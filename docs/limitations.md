# Limitations

Reverse-image APIs differ in authentication and response shape; configure a provider endpoint whose terms permit this use and adapt only the isolated client/parser. A visual match is not proof that the pictured person is the uploader. InsightFace accuracy varies with pose, lighting, occlusion, demographic factors, and model/runtime versions. Polygon Amoy is a public testnet: RPC availability, confirmations, and testnet token value are not production guarantees. The contract prevents duplicate hashes but does not validate source URLs or provider claims.
