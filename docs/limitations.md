# Limitations

Reverse-image APIs differ in authentication and response shape; configure a provider endpoint whose terms permit this use and adapt only the isolated client/parser. A candidate is accepted only when a face in its provider-returned Lens thumbnail meets the configured local InsightFace similarity threshold. This materially reduces unrelated URL selection, but biometric similarity is probabilistic and does not prove that the pictured person owns or uploaded the post. Thumbnails that are unavailable, hosted outside trusted Lens image domains, too small, or contain no detectable face fail closed. InsightFace accuracy varies with pose, lighting, occlusion, demographic factors, and model/runtime versions. Polygon Amoy is a public testnet: RPC availability, confirmations, and testnet token value are not production guarantees. The contract prevents duplicate hashes but does not validate source URLs or provider claims.
