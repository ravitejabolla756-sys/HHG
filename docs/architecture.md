# Architecture

Python owns input hashing, local InsightFace detection/encoding, provider calls, structured Lens parsing, candidate verification, selection, and canonical payload construction. Candidate verification downloads only provider-returned thumbnails from trusted Google/SerpApi image hosts, detects their faces locally, and compares their ephemeral embeddings with the single input-face embedding using cosine similarity. Candidates below the threshold, without a usable thumbnail, or without a detectable face are rejected. If none passes, execution stops before Node/ethers can register anything. Node/ethers owns the transaction and contract read-back. Embeddings and decoded thumbnails are held only in process memory and discarded after selection. The contract stores a hash-keyed record and emits an event; the hash prevents later payload tampering but does not prove identity or authorship of the source post.
